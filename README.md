# مواقيت الصلاة والآذان (Prayer Times App)

تطبيق ويب حديث لمواقيت الصلاة، التقويم الهجري، أوقات الأذان والإقامة لجميع المدن والدول بدقة فلكية عالية.

## التشغيل والتطوير (Local Development)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev
```

## بناء المشروع للنشر (Build for Production / GitHub Pages)

```bash
# بناء النسخة المجهزة للإنتاج
npm run build
```

## كيفية تفعيل GitHub Pages بدون صفحة بيضاء (GitHub Pages Setup)

إذا رفعت المشروع على GitHub وظهرت صفحة بيضاء، فالسبب هو أحد أمرين بسيطين في إعدادات المستودع (Settings):

### الطريقة الموصى بها (عبر GitHub Actions - تلقائية ومضمنة في المستودع):
1. اذهب إلى مستودعك على GitHub.
2. ادخل على **Settings** > ثم من القائمة الجانبية اختر **Pages**.
3. تحت خيار **Build and deployment**:
   - في **Source**، غيّر من `Deploy from a branch` إلى **`GitHub Actions`**.
4. ستقوم الأداة المرفقة في المشروع تلقائياً (`.github/workflows/deploy.yml`) ببناء المشروع ونشره خلال دقيقة واحدة وبدون أي صفحة بيضاء!

---

### الطريقة البديلة (عبر فرع جاهز / Deploy from branch):
إذا كنت تنشر مجلد `dist` يدوياً أو عبر فرع `gh-pages`:
1. ابنِ المشروع محلياً عبر: `npm run build`
2. ارفع محتويات مجلد `dist` إلى فرع `gh-pages`.
3. تم تضمين ملف `.nojekyll` وملف المسارات النسبية `base: './'` لضمان عمل الموقع مباشرة.

### ملف HTML مستقل وفوري (Single-file HTML):
يتوفر أيضاً ملف HTML كامل ومستقل بجميع الأكواد والتنسيقات ومواقيت الصلاة في المسار:
`public/standalone.html`
يمكن فتحه مباشرة في أي متصفح دون الحاجة لأي خادم أو بناء.
